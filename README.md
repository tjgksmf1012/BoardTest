# 포인트라운지 — 포인트로 아바타를 키우는 커뮤니티 게시판

활동(글쓰기·댓글·출석)할수록 포인트가 쌓이고, 포인트가 기준에 도달하면
프로필 아바타가 단계별로 해금되는 커뮤니티 게시판입니다.

> **처음 받으셨나요? → [실행방법.md](실행방법.md) 를 먼저 보세요.** (Node 설치 + 두 줄이면 실행)

아바타는 예시 이미지와 다른 오리지널 캐릭터로, 기본은 **코드로 그린 SVG 벡터 캐릭터**이며
`public/avatars/<id>.png` 이미지를 넣으면 그 이미지로 자동 교체됩니다 (`src/avatars.js`).

## 실행 방법

```bash
npm install
npm start   # 서버 실행 (http://localhost:3000)
npm test    # 단위 + HTTP 통합 테스트 (49개)
```

### Docker
```bash
docker build -t pointlounge .
docker run -e SESSION_SECRET=$(openssl rand -hex 32) \
  -p 3000:3000 -v $PWD/data:/app/data -v $PWD/uploads:/app/uploads pointlounge
```

> Node.js 20 이상 필요. 환경변수는 `.env.example` 참고. 설계 문서는 `docs/DESIGN.md`.
> 푸시·PR 시 GitHub Actions(CI)가 Node 20/22에서 자동으로 테스트를 돌립니다.

브라우저에서 http://localhost:3000 접속.
최초 실행 시 데모 데이터(공지·샘플 게시글)가 자동으로 생성됩니다.

## 주요 기능

### 게시판
- 글 목록(공지 고정, 페이지네이션, 검색, **본문 미리보기 한 줄**), 상세(조회수), 수정·삭제
- **말머리(카테고리) 5종**(자유·질문·정보·알바후기·구인구직) + 카테고리 필터
- **정렬(최신·추천·조회순) / 인기글 필터** — 네이버 카페·에브리타임식 목록 탐색
- 제목 50자 / 내용 5,000자 제한, 이미지 첨부 최대 5장(JPG·PNG, 장당 10MB)
- 이미지 첨부 미리보기·개별 삭제, 수정 화면에서 기존 이미지 삭제·추가
- 익명으로 작성(닉네임 숨김 + 추천 비활성화), 댓글 차단 옵션
- 댓글·대댓글, 추천(내 글 추천 불가, 중복 불가), 신고
- **스크랩(북마크)** — 관심 글을 저장하고 마이페이지에서 모아보기
- 로그인 필요 동작 시 **로그인 후 원래 위치로 복귀**, 로그인 실패 시 아이디 유지
- 포인트 랭킹 TOP 20 페이지

### 운영자 기능
- 공지 등록, 운영자 추천글 선정(+1,500P)
- **게시글 숨김 처리/복구**(soft hide) — 숨김 글은 일반 회원에게 비노출, 운영자만 열람·복구
- 게시글·댓글 삭제(영구)
- **신고 관리**: 신고 접수 글 목록에서 반려·숨김·삭제 처리
- **회원 관리**: 회원 목록·활동·포인트 확인, 부적절 회원 **제재/해제**
  (제재 회원은 로그인·활동 차단, 로그인 상태여도 즉시 로그아웃)

### 글쓰기 에디터 (서식 + 사진 위치 지정)
- **원하는 위치에 사진 삽입** — 커서를 둔 자리에 바로 들어가서 "사진 → 설명 → 사진" 구성이 가능
  (사진은 고르는 즉시 업로드되고 본문 안에 미리보기로 표시됨)
- 서식: **제목/소제목/본문**, 굵게, 밑줄, 글머리 목록, 번호 목록, 인용구
- **모바일 우선** — 툴바는 가로 스크롤되고 **[사진] 버튼은 오른쪽에 고정**되어 항상 손에 닿음,
  터치 영역 42px, iOS 자동 확대를 막는 16px 입력 글자 크기
- 외부 라이브러리 없이 직접 구현(추가 다운로드 0KB) — 느린 회선·무료 서버에서도 빠르게 열림
- 붙여넣기는 글자만 가져와 다른 사이트 서식이 딸려오지 않음
- **보안**: 저장 전 서버에서 `sanitize-html`로 정화. 스크립트·이벤트 핸들러·`style`·`iframe`은 제거되고,
  이미지는 우리 업로드 경로만, 링크는 http/https/mailto만 허용
- 옛 평문 글도 그대로 열람되고, 수정 화면에서는 문단으로 변환돼 편집 가능

### 댓글 · 베스트댓글
- 댓글 좋아요(에브리타임식) — 좋아요 3개 이상이면 **베스트댓글**로 상단 고정
- 댓글 좋아요는 순수 소셜 신호로 포인트를 지급하지 않음(기획 포인트 경제 유지)

### 레벨 · 배지
- 누적 포인트로 결정되는 **레벨/등급**(Lv.1 새싹 → Lv.7 전설), 닉네임 옆 뱃지 표시
- **업적 배지 8종**(첫 글·수다쟁이·인기스타·개근왕·운영자 픽·만렙 등) 프로필 전시

### 실시간 인기글
- 게시판 홈 상단 **🔥 지금 뜨는 글** — 최근 7일 추천 많은 글 TOP 5

### 알림
- 내 글 추천·댓글, 답글, 인기글/운영자 추천 선정 시 알림 발송
- 상단 🔔 벨의 안 읽은 개수 뱃지, 알림 목록 확인 시 자동 읽음 처리

### 출석 (출석부 연출)
- **그날 첫 접속 때 출석부가 뜨면서 자동으로 출석 처리** — "출석할까요?"라고 묻지 않음
  (어차피 하는 동작이라 확인 단계를 없앰). 하루 한 번만 노출
- **최근 7일 도장판**(오른쪽 끝이 오늘) + 오늘 칸에 도장이 떨어지는 애니메이션,
  연속 일수 카운트업, 적립 포인트 카운트업, 다음 보너스까지 진행률
- 3·7·30일 연속 달성 시 보너스 표시와 함께 카드가 금색으로 반짝이는 연출
- 화면 전환 없이 처리되고 헤더의 내 포인트도 즉시 갱신
- 출석 여부는 서버가 판단해 기기·브라우저가 바뀌어도 중복 지급·중복 노출 없음
- 달력·연속 출석 기록은 **마이페이지 > 출석 탭**에서 확인
- 모션 최소화 설정을 켠 사용자에겐 애니메이션 없이 결과만 표시

### 마이페이지
- **내 정보 / 출석 / 아바타 꾸미기** 3개 탭 구성
- 내가 쓴 글·댓글·스크랩한 글 모아보기
- 활동 통계(게시글·댓글·받은 추천·출석일)와 아바타 해금 현황
- **다음 해금까지 진행률 바** — 남은 포인트와 게이지로 성장 동기 부여

### 디자인 시스템
- **커스텀 SVG 라인 아이콘 세트**(`src/icons.js`)로 UI 이모지 전면 교체 — 통일된 굵기·스타일
- 로고 마크(P) + 워드마크, 딥 틸 + 웜 뉴트럴 팔레트
- 타이포 정리(자간·위계·스케일), 토스트/알림 문구의 이모지 절제
- (게이미피케이션 성격의 업적 배지·랭킹 메달은 의도적으로 이모지 유지)

### 접근성 (WCAG AA 지향)
- 본문·메타·뱃지·카테고리·레벨 색을 흰 배경 대비 4.5:1 이상으로 조정
- 키보드 포커스 표시(`:focus-visible`), 모션 최소화 설정 존중(`prefers-reduced-motion`)
- 폼 라벨 연결, 장식용 아바타/아이콘 `aria-hidden` 처리

### UI/UX 디테일
- **마이페이지 탭 분리**(내 정보 / 아바타 꾸미기) — 스크롤 길이 절반으로 축소
- 아바타·테두리 변경 후 아바타 탭 유지, 댓글 작성 후 댓글 위치로 이동
- 긴 페이지용 **맨 위로(↑) 버튼**
- 다음 해금 진행률 바(프로필·포인트 페이지·잠긴 티어별)
- 추천 버튼 클릭 팝 애니메이션, 버튼 눌림 피드백
- 상대 시간 표기("3시간 전", "1일 전")
- **모바일 하단 탭바**(홈·포인트·글쓰기 FAB·랭킹·MY)와 반응형 레이아웃
- 등장 애니메이션이 있는 토스트 알림, 한글 사진 첨부 버튼

## 기술 스택

- **백엔드**: Node.js + Express, 세션 로그인(scrypt 해시)
- **DB**: SQLite (better-sqlite3) — 별도 DB 서버 없이 파일 하나로 동작, 주요 컬럼 인덱스
- **뷰**: EJS 서버 사이드 렌더링 + 순수 CSS
- **업로드**: multer (파일 형식·용량·개수 검증)

## 보안

- 세션 쿠키 `HttpOnly` + `SameSite=Lax`(CSRF 완화), 운영 시 `Secure`
- 보안 헤더: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `x-powered-by` 제거
- 모든 SQL은 파라미터 바인딩(SQL 인젝션 방지), EJS 자동 이스케이프(XSS 방지)
- 입력 검증(길이·형식·화이트리스트), 오픈 리다이렉트 차단, 권한 검사(작성자/운영자)
- `SESSION_SECRET`은 환경변수로 설정(미설정 시 운영 환경에서 경고)

## 테스트

`npm test` — 총 31개 (`node --test`)
- 단위: 포인트 규칙·한도·연속출석, 레벨/업적, 카테고리, 알림
- 통합(실제 HTTP): 보안 헤더, 회원가입·포인트, 권한(삭제/추천), 추천 멱등성,
  카테고리 검증, XSS 이스케이프
