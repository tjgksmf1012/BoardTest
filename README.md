# 포인트라운지 — 포인트로 아바타를 키우는 커뮤니티 게시판

활동(글쓰기·댓글·출석)할수록 포인트가 쌓이고, 포인트가 기준에 도달하면
프로필 아바타가 단계별로 해금되는 커뮤니티 게시판입니다.

아바타는 예시 이미지와 다른 오리지널 캐릭터로, 외부 이미지 없이
**코드로 직접 그린 SVG 벡터 캐릭터**입니다 (`src/avatars.js`).

## 실행 방법

```bash
npm install
npm start   # 서버 실행
npm test    # 포인트 규칙 자동 테스트 (11개)
```

브라우저에서 http://localhost:3000 접속.
최초 실행 시 데모 데이터(공지·샘플 게시글)가 자동으로 생성됩니다.

### 데모 계정

| 계정 | 아이디 / 비밀번호 | 설명 |
|---|---|---|
| 운영자 | `admin` / `admin1234` | 공지 등록, 운영자 추천, 글·댓글 관리 |
| 샘플 회원 | `cherry` `mint` `street` `gold` / `test1234` | 포인트 보유량이 달라 해금 단계 비교 가능 |

## 주요 기능

### 게시판
- 글 목록(공지 고정, 페이지네이션, 검색), 상세(조회수), 수정·삭제
- **정렬(최신·추천·조회순) / 인기글 필터** — 네이버 카페·에브리타임식 목록 탐색
- 제목 50자 / 내용 5,000자 제한, 이미지 첨부 최대 5장(JPG·PNG, 장당 10MB)
- 이미지 첨부 미리보기·개별 삭제, 수정 화면에서 기존 이미지 삭제·추가
- 익명으로 작성(닉네임 숨김 + 추천 비활성화), 댓글 차단 옵션
- 댓글·대댓글, 추천(내 글 추천 불가, 중복 불가), 신고
- **스크랩(북마크)** — 관심 글을 저장하고 마이페이지에서 모아보기
- 운영자: 공지 등록, 운영자 추천글 선정, 글·댓글 숨김(삭제), **신고 관리 페이지**
- 포인트 랭킹 TOP 20 페이지

### 알림
- 내 글 추천·댓글, 답글, 인기글/운영자 추천 선정 시 알림 발송
- 상단 🔔 벨의 안 읽은 개수 뱃지, 알림 목록 확인 시 자동 읽음 처리

### 마이페이지
- 내가 쓴 글·댓글·스크랩한 글 모아보기
- 활동 통계(게시글·댓글·받은 추천·출석일)와 아바타 해금 현황
- **다음 해금까지 진행률 바** — 남은 포인트와 게이지로 성장 동기 부여

### UI/UX 디테일
- 다음 해금 진행률 바(프로필·포인트 페이지·잠긴 티어별)
- 추천 버튼 클릭 팝 애니메이션, 버튼 눌림 피드백
- 상대 시간 표기("3시간 전", "1일 전")
- **모바일 하단 탭바**(홈·출석·글쓰기 FAB·랭킹·MY)와 반응형 레이아웃
- 등장 애니메이션이 있는 토스트 알림, 한글 사진 첨부 버튼

### 포인트 제도
| 활동 | 포인트 | 제한 |
|---|---|---|
| 회원가입 | 1,000P | 최초 1회 |
| 출석체크 | 100P | 하루 1회 |
| 일반 게시글 | 300P | 하루 3개까지 |
| 익명 게시글 | 100P | 하루 3개까지 |
| 댓글·대댓글 | 100P | 하루 10개까지 |
| 추천받기 | 10P | 추천 1개당 |
| 인기글 선정 (추천 10개↑) | 1,000P | 글당 1회 |
| 운영자 추천글 | 1,500P | 글당 1회 |
| 연속 출석 3 / 7 / 30일 | 500 / 1,000 / 3,000P | 연속 달성 시 |

포인트는 활동 제한이 아니라 지급 기준입니다(한도 초과 시 글은 등록되고 포인트만 미지급).

## 기술 스택

- **백엔드**: Node.js + Express, 세션 로그인(scrypt 해시)
- **DB**: SQLite (better-sqlite3) — 별도 DB 서버 없이 파일 하나로 동작
- **뷰**: EJS 서버 사이드 렌더링 + 순수 CSS
- **업로드**: multer (파일 형식·용량·개수 검증)
