# 포인트라운지 — 포인트로 아바타를 키우는 커뮤니티 게시판

활동(글쓰기·댓글·출석)할수록 포인트가 쌓이고, 포인트가 기준에 도달하면
프로필 아바타가 단계별로 해금되는 커뮤니티 게시판입니다.

> **처음 받으셨나요? → [실행방법.md](실행방법.md) 를 먼저 보세요.** (Node 설치 + 두 줄이면 실행)

아바타는 예시 이미지와 다른 오리지널 캐릭터로, 기본은 **코드로 그린 SVG 벡터 캐릭터**이며
`public/avatars/<id>.png` 이미지를 넣으면 그 이미지로 자동 교체됩니다 (`src/avatars.js`).

## 실행 방법

```bash
npm install
npm start   # 서버 실행 (http://localhost:3000)
npm test    # 단위 + HTTP 통합 테스트 (137개)
```

### Docker
```bash
docker build -t pointlounge .
docker run -e SESSION_SECRET=$(openssl rand -hex 32) \
  -p 3000:3000 -v $PWD/data:/app/data -v $PWD/uploads:/app/uploads pointlounge
```

> Node.js 20 이상 필요. 환경변수는 `.env.example` 참고. 설계 문서는 `docs/DESIGN.md`.
> 푸시·PR 시 GitHub Actions(CI)가 Node 20/22에서 자동으로 테스트를 돌립니다.

브라우저에서 http://localhost:3000 접속.
최초 실행 시 데모 데이터(공지·샘플 게시글)가 자동으로 생성됩니다.

## 주요 기능

### 게시판
- 글 목록(공지 고정, 페이지네이션, 검색), 상세(조회수), 수정·삭제
- **말머리(카테고리) 5종**(자유·질문·정보·알바후기·구인구직) — 밑줄 탭으로 전환
- **정렬은 선택 상자, 전체글/인기글은 세그먼트** (아래 '목록 화면 정리' 참고)
- 제목 50자 / 내용 5,000자 제한, 이미지 첨부 최대 5장(JPG·PNG, 장당 10MB)
- 이미지 첨부 미리보기·개별 삭제, 수정 화면에서 기존 이미지 삭제·추가
- 익명으로 작성(닉네임 숨김 + 추천 비활성화), 댓글 차단 옵션
- 댓글·대댓글, 추천(내 글 추천 불가, 중복 불가), 신고
- **스크랩(북마크)** — 관심 글을 저장하고 마이페이지에서 모아보기
- 로그인 필요 동작 시 **로그인 후 원래 위치로 복귀**, 로그인 실패 시 아이디 유지
- 포인트 랭킹 TOP 20 페이지

### A사이트 연동 (계정을 두 번 만들지 않기)
이 커뮤니티는 **이미 회원을 가진 알바채용 사이트('A사이트') 안에 들어가는 기능**이에요.
A사이트 회원에게 커뮤니티 계정을 하나 더 만들게 하면 비밀번호·탈퇴·정지가 두 곳에서 따로 놀고,
보관할 이유가 없는 비밀번호를 한 벌 더 떠안게 돼요. 그래서 신원은 A사이트에 맡기고
커뮤니티는 **프로필(포인트·아바타·활동)만** 갖도록 분리했어요.

- `AUTH_MODE=standalone` (기본) — 자체 아이디/비밀번호. **혼자 띄워 시연할 때 그대로 동작**
- `AUTH_MODE=host` — A사이트가 넘겨준 회원번호를 신뢰. **커뮤니티 회원가입이 사라짐**
  - A사이트는 서명된 토큰(HMAC-SHA256, 기본 5분)만 `?sso=`로 붙여 보내면 됨
  - 회원번호로 프로필을 찾고 없으면 그 자리에서 생성 → 기획서의 가입 1,000P를 **첫 방문**에 지급
  - 토큰은 주소창·방문기록에 남지 않게 즉시 제거, 세션 ID는 새로 발급(세션 고정 방어)
  - 운영자 권한·정지 여부의 원장도 A사이트 (토큰의 `admin` / `banned`)
- 연동 방식이 바뀌어도 **`src/identity.js` 한 파일만** 고치면 됨

> 규격·예시 코드·A사이트에 여쭐 항목은 **[docs/연동가이드.md](docs/연동가이드.md)** 에 정리해 뒀어요.

### 운영자 기능
- 공지 등록, 운영자 추천글 선정(+1,500P)
- **게시글 숨김 처리/복구**(soft hide) — 숨김 글은 일반 회원에게 비노출, 운영자만 열람·복구
- 게시글·댓글 삭제(영구)
- **신고 관리**: 신고 접수 글 목록에서 반려·숨김·삭제 처리
- **회원 관리**: 회원 목록·활동·포인트 확인, 부적절 회원 **제재/해제**
  (제재 회원은 로그인·활동 차단, 로그인 상태여도 즉시 로그아웃)

### 글쓰기 에디터 (서식 + 사진 위치 지정)
- **원하는 위치에 사진 삽입** — 커서를 둔 자리에 바로 들어가서 "사진 → 설명 → 사진" 구성이 가능
  (사진은 고르는 즉시 업로드되고 본문 안에 미리보기로 표시됨)
- 서식: **제목/소제목/본문**, 굵게, 밑줄, 글머리 목록, 번호 목록, 인용구
- **모바일 우선** — 툴바는 가로 스크롤되고 **[사진] 버튼은 오른쪽에 고정**되어 항상 손에 닿음,
  터치 영역 42px, iOS 자동 확대를 막는 16px 입력 글자 크기
- 외부 라이브러리 없이 직접 구현(추가 다운로드 0KB) — 느린 회선·무료 서버에서도 빠르게 열림
- 붙여넣기는 글자만 가져와 다른 사이트 서식이 딸려오지 않음
- 사진은 글당 **최대 5장**(서버·에디터 양쪽에서 제한), 남은 장수는 [사진] 버튼에 표시
- **보안**: 저장 전 서버에서 `sanitize-html`로 정화. 스크립트·이벤트 핸들러·`style`·`iframe`은 제거되고,
  이미지는 우리 업로드 경로만, 링크는 http/https/mailto만 허용
- 업로드 남용 방지(1인 10분 30장)와, 어느 글에도 속하지 않는 오래된 파일 자동 정리

### 사진 자동 최적화
요즘 폰 사진은 4,000px·수 MB라 그대로 두면 무료 서버 저장공간이 금방 차고, 모바일에서 글 하나 여는 데
수 MB를 내려받게 돼요. 올라온 사진은 원본을 디스크에 쓰지 않고 **메모리에서 다듬은 뒤** 저장해요.

- **긴 변 1,600px로 축소** (작은 사진은 억지로 늘리지 않음) — 실측 **618KB → 67KB (89% 절감)**
- **촬영 정보(EXIF) 제거** — 폰 사진에 박힌 **GPS 위치가 그대로 공개되는 것을 방지**
- **회전 보정** — 세로로 찍은 사진이 눕지 않도록 회전을 실제 픽셀에 반영한 뒤 정보를 제거
- **형식 유지** — PNG는 PNG로 저장(스크린샷 글자가 뭉개지지 않도록), JPEG는 품질 82로 재압축
- 이미지가 아닌 파일이나 깨진 파일은 오류 메시지로 안내
- 옛 평문 글도 그대로 열람되고, 수정 화면에서는 문단으로 변환돼 편집 가능

### 댓글 · 베스트댓글
- 댓글 좋아요(에브리타임식) — 좋아요 3개 이상이면 **베스트댓글**로 상단 고정
- 댓글 좋아요는 순수 소셜 신호로 포인트를 지급하지 않음(기획 포인트 경제 유지)
- **댓글 수정** — 본인 댓글만 고칠 수 있고, 수정하면 `수정됨` 표시가 남음
  (운영자도 남의 댓글 내용은 못 바꾸고 삭제만 가능)
- **답글 더보기** — 답글이 3개 이상이면 앞 2개만 보이고 나머지는 접어둠
- **댓글 페이지네이션** — 최상위 댓글 20개 단위로 나눠 그림(답글은 부모와 같은 쪽에 함께 실림).
  댓글을 달면 **그 댓글이 보이는 쪽**으로 돌아옴
- 답글이 달린 댓글을 지우면 `삭제된 댓글이에요` 자리만 남기고 **남이 단 답글은 보존**
  (답글이 없으면 흔적 없이 삭제, 답글이 모두 지워지면 남은 자리도 자동 정리)

### 공개 프로필 (다른 사람 프로필 보기)
- 글 작성자·댓글 작성자·랭킹에서 닉네임/아바타를 누르면 그 사람의 프로필로 이동
- 레벨·포인트·랭킹 순위·활동 통계·획득한 배지·작성한 글을 보여줌
- **익명으로 쓴 글은 제외**되고, 스크랩·알림처럼 남에게 보일 이유가 없는 정보는 표시하지 않음
- 내 프로필 주소로 들어가면 마이페이지로 넘어감

### 레벨 · 배지
- 누적 포인트로 결정되는 **레벨/등급**(Lv.1 새싹 → Lv.7 전설), 닉네임 옆 뱃지 표시
- **업적 배지 8종**(첫 글·수다쟁이·인기스타·개근왕·운영자 픽·만렙 등) 프로필 전시

### 실시간 인기글
- 게시판 홈 상단 **🔥 지금 뜨는 글** — 최근 7일 추천 많은 글 TOP 5

### 알림
- 내 글 추천·댓글, 답글, 인기글/운영자 추천 선정 시 알림 발송
- 상단 🔔 벨의 안 읽은 개수 뱃지, 알림 목록 확인 시 자동 읽음 처리
- **실시간 수신(SSE)** — 새로고침하지 않아도 벨 뱃지가 바뀌고 화면 아래에 안내가 뜸.
  안내를 누르면 해당 글로 이동. 연결이 끊기면 브라우저가 자동 재접속하고,
  계속 실패하면 1분 간격 조회로 대체(서버리스·구형 브라우저 대비).
  한 사람당 연결 5개까지, 25초마다 신호를 보내 중간 서버가 끊지 않게 유지

### 출석 (출석부 연출)
- **그날 첫 접속 때 출석부가 뜨면서 자동으로 출석 처리** — "출석할까요?"라고 묻지 않음
  (어차피 하는 동작이라 확인 단계를 없앰). 하루 한 번만 노출
- **최근 7일 도장판**(오른쪽 끝이 오늘) + 오늘 칸에 도장이 떨어지는 애니메이션,
  연속 일수 카운트업, 적립 포인트 카운트업, 다음 보너스까지 진행률
- 3·7·30일 연속 달성 시 보너스 표시와 함께 카드가 금색으로 반짝이는 연출
- 화면 전환 없이 처리되고 헤더의 내 포인트도 즉시 갱신
- 출석 여부는 서버가 판단해 기기·브라우저가 바뀌어도 중복 지급·중복 노출 없음
- 달력·연속 출석 기록은 **마이페이지 > 출석 탭**에서 확인
- 모션 최소화 설정을 켠 사용자에겐 애니메이션 없이 결과만 표시
- 팝업이 뜨면 포커스가 팝업 안으로 이동하고 Tab이 팝업 안에서만 순환(포커스 트랩),
  Esc·배경 클릭으로 닫히며 닫을 때 원래 위치로 포커스 복귀, 열린 동안 배경 스크롤 잠금

### 마이페이지
- **내 정보 / 출석 / 아바타 꾸미기** 3개 탭 구성
- 내가 쓴 글·댓글·스크랩한 글 모아보기
- 활동 통계(게시글·댓글·받은 추천·출석일)와 아바타 해금 현황
- **다음 해금까지 진행률 바** — 남은 포인트와 게이지로 성장 동기 부여

### 성능
글 20,000건 · 댓글 60,000건 · 추천 88,000건을 넣고 측정한 응답시간(중앙값)이에요.

| 화면 | 개선 전 | 개선 후 |
|---|---|---|
| 목록 1페이지 | 57ms | **20ms** |
| 정렬: 추천순 | 100ms | **17ms** |
| 정렬: 조회순 | 85ms | **16ms** |
| 검색 | 43ms | 43ms |
| 글 상세 | 4ms | 4ms |

- **추천 수를 글에 함께 저장(비정규화)** — 매번 세어 정렬하면 글 수만큼 훑어야 해서
  `like_count` 컬럼 + 인덱스로 바꿔 정렬을 인덱스만으로 끝냄(임시 정렬 제거)
- **조회순 인덱스** 추가로 동일하게 임시 정렬 제거
- **페이지 수 계산 COUNT**가 본문까지 읽던 것을 커버링 인덱스로 전환(15ms → 1ms)
- **검색은 SQLite FTS5 전문검색으로 전환** (아래 참고)

### 전문검색 (한글에 맞춘 FTS5)
`LIKE '%검색어%'`는 앞에 와일드카드가 있어 인덱스를 못 타고 매번 전체를 훑었어요. SQLite FTS5로 바꿨는데,
한글은 토크나이저 선택이 까다로워서 다음을 확인하고 정했어요.

| 방식 | 문제 |
|---|---|
| `unicode61`(기본) | 띄어쓰기로 단어를 나눠서 **"주말알바"에서 "알바"를 못 찾음** |
| `trigram` | 부분일치는 되지만 **3글자 이상만** 매칭 — "알바"·"카페" 검색 불가 |
| **바이그램 색인** (채택) | 본문을 두 글자씩 잘라 저장 → **두 글자 검색부터 부분일치 모두 동작** |

- 검색어도 같은 방식으로 잘라 AND로 묶고, 드물게 생기는 오탐은 원문 대조로 걸러냄
- 검색 결과가 기존 `LIKE` 방식과 **완전히 동일함을 15개 낱말로 대조 검증** (누락 0건)
- 한 글자 검색은 색인으로 좁힐 수 없어 기존 방식으로 처리

20,000글 기준 검색 응답시간(중앙값):

| 검색 | 개선 전 | 개선 후 |
|---|---|---|
| 흔치 않은 낱말(12건 매칭) | 43ms | **6.5ms** |
| 결과 없음 | 43ms | **4.1ms** |
| 매우 흔한 낱말(1.9만건 매칭) | 43ms | **22ms** |

### 다크 모드
- 기기 설정(`prefers-color-scheme`)을 자동으로 따르고, 상단바 버튼으로 직접 바꿀 수도 있어요
  (직접 고른 값은 저장되어 다음 방문에도 유지)
- 화면이 그려지기 전에 테마를 적용해 **밝은 화면이 번쩍이는 현상 없음**
- 색은 전부 CSS 변수로 두고 팔레트만 교체하는 방식
- **두 테마 모두 WCAG AA 대비 통과** (본문 11:1 이상, 버튼·칩·말머리 4.5:1 이상)
  - 밝은 청록 위에는 흰 글씨 대신 어두운 글씨를 써서 다크 모드 가독성 확보
  - 말머리 색도 다크용 밝은 색을 따로 지정
  - 이 과정에서 기존 라이트 모드 강조색이 흰 글씨 대비 3.74로 AA 미달이던 것도 함께 수정

### 보안: CSRF 토큰
쿠키가 `SameSite=Lax`라 다른 사이트발 POST에는 이미 쿠키가 붙지 않지만, 그건 브라우저 동작에 기대는
방어라서 표준대로 토큰도 함께 확인해요.

- 세션마다 무작위 토큰을 발급하고, **모든 쓰기 요청**(폼 28곳 + fetch 2곳)에서 검증
- 토큰이 없거나 다른 세션의 토큰이면 **403**으로 막고 안내 화면을 보여줌
- JSON 요청은 `X-CSRF-Token` 헤더로도 보낼 수 있음
- 토큰 발급과 검증을 분리해, 검증 실패 화면도 정상적으로 그려지도록 함

### 공유하기 (링크 미리보기)
- 글 주소를 카카오톡·트위터 등에 붙이면 **제목과 본문 요약, 첨부 사진**이 미리보기로 뜸
  (Open Graph / Twitter Card 메타태그)
- **익명글은 본문이 미리보기에 실리지 않아** 작성 내용이 밖으로 새지 않음
- 숨김 처리된 글도 내용이 노출되지 않음

### 목록 화면 정리 (기획 시안에 맞춤)
기획 시안은 **흰 바탕 + 얇은 구분선 + 밑줄 탭**인데, 화면에는 알약(pill) 칩이 11개 깔려 있어
결이 달랐어요. 390px 기준으로 **첫 게시글이 1,300px 아래**에 있어 한 화면 반을 내려야 글이 보였고요.

| | 전 | 후 |
|---|---|---|
| 첫 게시글까지 | 1,300px | **479px** |
| 말머리 6개 | 알약 칩 → 두 줄로 밀림 | **밑줄 탭 한 줄** (320px에서도 안 밀림) |
| 정렬 | 버튼 3개 | **선택 상자 1개** |
| 전체글/인기글 | 진한 알약 버튼 | **세그먼트** |

- **말머리**: 칩은 글자보다 좌우 여백이 커서 여섯 개가 두 줄로 밀리고, 한 줄로 붙이면 가로 스크롤이
  생겨요. 가로 스크롤 칩은 *스크롤이 있다는 신호가 없어 뒤쪽 항목을 못 찾는* 문제도 알려져 있고요.
  글자만 남긴 밑줄 탭으로 바꾸니 같은 글자수가 **320px에도 한 줄**에 들어가요
- **정렬 ↔ 필터 구분**: 필터는 *목록에 들어갈 글*을 바꿔서 고를 수 있는 값이 다 보여야 하지만,
  정렬은 *순서만* 바꾸고 자주 건드리지도 않아 지금 값만 보이면 돼요. 그래서 필터는 세그먼트로 남기고
  정렬만 선택 상자로 접었어요 (기획 시안의 댓글 정렬 `최신순 ⌄`과 같은 방식)
- 조건이 서로를 지우지 않아요 — 인기글로 넘어가거나 검색해도 보고 있던 말머리가 유지돼요
- 제목 옆 `[3]`은 오른쪽 댓글 수와 같은 말이라 뺐고, 대신 **제목을 두 줄까지** 보여줘요
  (모바일에서 열두 글자쯤에서 잘리던 문제)

### 점 3개(더보기) 메뉴
신고·수정·삭제·운영자 기능은 어쩌다 한 번 쓰는데, 버튼으로 늘어놓으면 정작 본문보다 눈에 띄어요.
기획안의 '게시글 내 점 3개 메뉴' 그대로 한 곳에 모았어요.

- 밖에 남는 것: **목록 · 스크랩 · 추천** (댓글은 **좋아요 · 답글**)
- 메뉴 안: 내 글·댓글이면 **수정하기/삭제하기**, 남의 것이면 **신고하기**,
  운영자에게는 구분선 아래 **운영자 추천 / 숨김 처리**
- 바깥 클릭·Esc로 닫히고, 한 번에 하나만 열려요. 화면 밖으로 나가면 반대쪽에 붙어요
- 자바스크립트가 없으면 열리지 않으므로 `hidden`으로 시작하고 `aria-expanded`로 상태를 알려요

## 기술 스택

- **백엔드**: Node.js + Express, 세션 로그인(scrypt 해시)
- **DB**: SQLite (better-sqlite3) — 별도 DB 서버 없이 파일 하나로 동작, 주요 컬럼 인덱스
- **뷰**: EJS 서버 사이드 렌더링 + 순수 CSS
- **업로드**: multer (파일 형식·용량·개수 검증)

## 보안

- 세션 쿠키 `HttpOnly` + `SameSite=Lax`(CSRF 완화), 운영 시 `Secure`
- 보안 헤더: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `x-powered-by` 제거
- 모든 SQL은 파라미터 바인딩(SQL 인젝션 방지), EJS 자동 이스케이프(XSS 방지)
- 입력 검증(길이·형식·화이트리스트), 오픈 리다이렉트 차단, 권한 검사(작성자/운영자)
- `SESSION_SECRET`은 환경변수로 설정(미설정 시 운영 환경에서 경고)
