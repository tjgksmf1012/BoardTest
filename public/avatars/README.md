# 아바타 이미지 폴더

이 폴더에 `<아바타id>.png`(또는 .jpg/.webp) 파일을 넣으면,
게시판 전체에서 해당 아바타가 **그 이미지로 자동 교체**됩니다.
파일이 없는 아바타는 코드로 그린 벡터(SVG)로 표시됩니다.

- 예: `basic-01.png` 를 넣으면 "러블리 핑크" 자리에 그 이미지가 사용됨
- 권장: 정사각형(512×512 이상), 인물이 가운데 오도록 (원형으로 잘림)
- 서버를 재시작하면 새 이미지가 반영됩니다.
