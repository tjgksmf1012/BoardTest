# 배포 방법 (다른 사람이 URL로 접속해서 테스트하게 하기)

> ✅ **현재 배포된 주소: https://pointlounge.onrender.com**
> 누구나 바로 접속해 테스트할 수 있어요. (무료 서버라 15분 무접속 시 잠들고, 첫 접속에 30초쯤 깨어나는 시간이 걸릴 수 있어요 — 정상)
> 데모 계정: 운영자 `admin / admin1234`, 일반 `gold / test1234` (그 외 mint·cherry·street 도 test1234)

이 프로그램은 SQLite·세션을 쓰는 일반 웹 서버라, **컨테이너형 호스팅**에 올리면 돼요.
아래는 **무료**로 가장 쉬운 Render.com 기준이에요. (저장소에 `render.yaml`이 이미 있어요.)

## Render로 배포 (약 5분)
1. https://render.com 가입/로그인 (GitHub 계정으로 로그인하면 편함)
2. 상단 **New +** → **Blueprint** 클릭
3. 이 GitHub 저장소(`BoardTest`)를 선택 → **Apply**
   - `render.yaml`을 자동으로 읽어 `pointlounge` 웹 서비스를 만들어요
   - `SESSION_SECRET`은 Render가 자동 생성
4. 빌드가 끝나면(수 분) `https://pointlounge-xxxx.onrender.com` 같은 **공개 주소**가 나와요
5. 그 주소를 교수님·테스터에게 공유하면 누구나 접속해서 테스트 가능

> 참고
> - 무료 플랜은 15분간 접속이 없으면 잠들고, 다음 접속 때 다시 깨느라 첫 로딩이 30초쯤 걸려요(정상).
> - 무료 플랜은 디스크가 임시라 서버가 재시작되면 작성한 글이 초기화되고 **데모 데이터가 다시 채워져요**. 테스트용으론 충분해요.
> - 계속 유지되는 데이터가 필요하면 유료 디스크(또는 외부 DB)로 바꾸면 되는데, 데모/제출용이면 불필요해요.

## 다른 호스팅도 가능
- **Railway / Fly.io** 등 컨테이너 호스팅이면 어디든 동작해요 (`Dockerfile` 포함).
- 로컬에서 직접 실행만 할 거면 배포 없이 `실행방법.md`대로 `npm install` → `npm start` 면 됩니다.
