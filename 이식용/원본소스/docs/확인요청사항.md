## 지금 막혀 있는 것

이 세 가지가 있어야 다음으로 넘어갑니다.

### 1. 서버가 어떤 상태인지

`이식용/서버확인.php` 를 웹 폴더에 올리시고 브라우저로 여신 뒤,
나온 화면을 그대로 보내 주시면 됩니다.
PHP 버전과 MySQL 버전, 문자셋, 시간대가 한 화면에 나옵니다.

보시고 나면 그 파일은 꼭 지워 주세요.
서버 설정이 그대로 드러나는 파일이라 남겨 두면 위험합니다.

이걸 알아야 아래 두 가지가 확실해집니다.

- MySQL 이 5.5.3 이상이면 `install.sql` 의 `utf8` 을 `utf8mb4` 로 바꿔야 합니다.
  안 그러면 이모지가 깨집니다. 옛날 `utf8` 은 한 글자에 3바이트까지만 담는데
  이모지는 4바이트라서 그렇습니다.
- PHP 와 MySQL 시간대가 둘 다 한국이 아니면 출석과 하루 한도가 자정 근처에서 하루씩 어긋납니다.

### 2. 캐릭터 그림 두 가지

여성 캐릭터 4종을 아직 못 받았습니다. 자리는 비워 두었습니다.
이벤트 한정 캐릭터(봄, 크리스마스, 할로윈)도 그림이 오면 바로 넣겠습니다.
512×512 크기 PNG 로 주시면 됩니다.

### 3. 캐릭터 값을 어떻게 매길까요

기획서에 두 가지가 섞여 있어서 어느 쪽인지 여쭙습니다.

| | |
|---|---|
| 가 | 단계별로. 스페셜 헤어 5,000P, 프리미엄 의상 10,000P, 움직이는 테두리 20,000P |
| 나 | 한 값으로. 캐릭터 한 종에 2,000P (테두리만 20,000P) |

지금은 '나' 로 만들어 두었습니다.
'가' 로 가더라도 `cm_config.php` 의 값만 바꾸면 되니 부담 없이 정해 주셔도 됩니다.

## A사이트 개발 담당자분께 여쭐 것

커뮤니티를 A사이트 로그인에 붙이는 부분입니다.
붙이는 방법과 예시 코드는 [연동가이드](연동가이드.md)에 정리해 두었으니
그대로 전달해 주시면 됩니다.

4. 회원을 구분하는 고유 번호가 무엇인가요? 숫자인지 문자인지,
   그리고 한 번 정해지면 안 바뀌는 값인지 알려 주세요.
5. 닉네임을 커뮤니티에 같이 넘겨 주실 수 있나요? 어려우면 커뮤니티에서 따로 정하겠습니다.
6. 운영자 권한을 A사이트 회원 정보로 알 수 있나요?
7. 회원이 탈퇴하거나 정지되면 커뮤니티에 알려 주실 수 있나요?
8. 커뮤니티가 A사이트와 같은 도메인에 붙나요, 아니면 다른 주소로 열리나요?
9. A사이트 서버는 무슨 언어로 되어 있나요?
   알려 주시면 예시 코드를 그 언어로 다시 드리겠습니다.

그리고 나눠 가질 비밀키가 하나 필요합니다.
32자 이상으로 만들어 서버 환경변수에만 넣어 주세요.
`openssl rand -hex 32` 를 치시면 나옵니다.
손으로 지어내지 마시고, 코드 안에도 적어 두지 말아 주세요.
이 키가 새면 아무나 아무 회원인 척 들어올 수 있습니다.

## 그동안 정해진 것

받은 답을 그대로 반영해 두었습니다.
혹시 아래와 다르게 알고 계신 게 있으면 말씀해 주세요.

| 무엇 | 어떻게 정해졌나 |
|---|---|
| 게시판 구성 | 게시판 하나에 말머리를 붙이는 방식. 따로 나누지 않음 |
| 말머리 | 자유, 질문, 이벤트. 이벤트는 운영자만 글을 쓸 수 있고 '정보' 는 뺐습니다 |
| 한 쪽에 보이는 글 | 15개 |
| 이전글·다음글 | 보고 있던 목록(말머리·검색·정렬)을 그대로 따라갑니다 |
| 정렬과 인기 글 | 최근 며칠로 자르지 않고 전체 기간에서 뽑습니다 |
| 랭킹 | TOP 20. 여성회원만 올라가고 남성·업소 회원과 운영자는 빠집니다. 다만 화면 글에는 '여성' 이라고 쓰지 않았습니다 |
| 베스트댓글 | 좋아요 4개 이상 중 딱 하나. 복사하지 않고 자리만 위로 옮깁니다 |
| 검색 | 제목과 본문에 더해 닉네임으로도 찾습니다. 익명 글은 닉네임으로 안 걸립니다 |
| 캐릭터 | 저희가 새로 만든 것으로 확정. 246종이고 남성·업소 회원용도 있습니다 |
| 서버와 DB | 기존 호스팅(PHP 5.1, MySQL)에 얹기로 하고 그에 맞춰 PHP 로 옮겼습니다 |
| 계정 | A사이트 로그인에 붙이는 방식. 커뮤니티에 따로 가입하지 않습니다 |

## 만들면서 헷갈렸던 것

두 가지는 저희가 잘못 알아들었다가 고쳤습니다.
혹시 지금도 뜻이 다르면 말씀해 주세요.

베스트댓글 기준을 처음에는 좋아요 5개로 잡았습니다.
쪽지에 "4개 이하는 지정 안 되게" 라고 적혀 있어서 글자 그대로 따른 것이었는데,
원래 보시던 화면이 4개짜리였다고 하셔서 4개로 내렸습니다.
지금은 좋아요가 딱 4개인 댓글도 베스트가 됩니다.

캐릭터 테두리는 크기를 세 번 고쳤습니다.
작으면 캐릭터가 삐져나오고 키우면 테두리가 붕 떠 보였는데,
알고 보니 크기 문제가 아니라 테두리 그림 아홉 장이 전부
가운데에서 조금씩 치우쳐 있던 것이었습니다. 지금은 그만큼 밀어서 맞춰 두었습니다.

막히시는 곳 있으면 말씀 주세요. 바로 맞춰 드리겠습니다.
