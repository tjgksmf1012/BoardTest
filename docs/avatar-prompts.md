# 아바타 이미지 생성 프롬프트 키트 (복붙용)

참고 예시(반실사 애니 미소녀 초상) **수준**으로, 하지만 **예시와 다른 오리지널 캐릭터**를
뽑기 위한 프롬프트입니다. 아래 프롬프트는 **그대로 복사-붙여넣기** 하면 됩니다.

## 워크플로
1. 아래 표에서 프롬프트를 복사해 이미지 AI에 붙여넣기 (툴별 형식은 맨 아래 참고).
2. 정사각형으로 크롭 → `public/avatars/<id>.png` 로 저장.
3. 서버 재시작 → 게시판 전체 반영. (id 목록: `public/avatars/README.md`)

> **세트 통일 팁:** 12종을 뽑을 땐 같은 **모델·시드·스타일 레퍼런스**를 고정하고,
> 아래 프롬프트에서 **머리색/헤어스타일/의상/악세만** 바뀌도록 하세요.
>
> ⭐ **옆모습 방지(중요):** 아바타는 정면 얼굴이 잘 나와야 해요. 프롬프트에
> **`front view, looking at viewer, face centered`** 를 꼭 넣으세요.
> (네거티브에 `profile, side view, from behind, looking away` 추가하면 더 확실)

## 툴별 형식

- **PixAI / SeaArt / Mage / NovelAI (SD 계열)**: 위 프롬프트 그대로 붙여넣고, **네거티브 프롬프트** 추가:
  ```
  lowres, blurry, bad anatomy, extra fingers, text, watermark, logo, deformed, nsfw, harsh shadows
  ```
  모델은 애니 특화(SDXL) 추천: *Animagine XL, Illustrious, Pony Diffusion* 등.
- **Midjourney**: 프롬프트 끝에 붙이기 → `--niji 6 --ar 1:1 --style raw`
  세트 통일은 첫 이미지 URL을 `--sref <url>` 로 이후 컷에 재사용.
- **DALL·E 3 (ChatGPT / Bing / Copilot)**: 그대로 붙여넣기. "square 1:1 avatar"만 확실히.
- **Gemini (Nano Banana)**: 먼저 basic-01을 만들고, "**같은 캐릭터·같은 화풍으로 머리색만 ○○, 의상은 ○○로**" 식으로 편집 요청하면 세트 통일이 쉬움.
